# Aeon's End – Nemesis Companion (App 0.2)

Web app per il telefono che gestisce il mazzo della nemesi di **Aeon's End**: lo prepara, pesca le carte, tiene il conto
di token e vita e guida il turno nemesi.

- Sito: <https://lorenzvittori.github.io/AeonsEnd_App_0.2/>
- HTML, CSS e JavaScript senza framework né build; pubblicato su GitHub Pages da `.github/workflows/pages.yml`.
- `version.json` va aumentato a ogni modifica di CSS o JS (cache-busting).

Tutto il resto (uso, architettura, dati, regole di lavoro, test, tag di ripristino) è in
[CONTESTO_SVILUPPO.md](CONTESTO_SVILUPPO.md).
